# Rebrand: Tarsee → Aqila

**Status:** In progress

## Why?

"Tarsee" was named after the tarsier (the animal that never closes its eyes — like a 24/7 agent). However, it's too similar in name and pronunciation to **Tarsi**, an existing finance app by Bryl Lim. No intentional copying — different product, different space — but we're rebranding to avoid confusion and respect the Tarsi team.

## New Name: Aqila

From **Aquila** (Latin for eagle), inspired by the **Philippine Eagle** — the largest and most powerful eagle in the world, endemic to the Philippines.

- Always watching, always on
- Built in the Philippines 🇵🇭

## What's Changing

- Repo name: `Tarsee` → `Aqila`
- All code references, branding, UI text
- Railway template URL
- Discord server/bot name
- README, package.json, Docker image

## What's NOT Changing

- All features stay the same
- Your data on `/data` volume is safe — just redeploy
- Same Claude Code SDK under the hood
- Same deploy process

## Timeline

Rebrand is in progress. Existing Tarsee deployments will continue to work — just point your Railway service to the new repo when it's ready.
